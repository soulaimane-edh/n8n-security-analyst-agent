# Security Policy

## Reporting a vulnerability

Please do **not** file public issues that include credentials, sensitive emails, customer data, or workable exploit chains. Contact the project maintainer privately through the GitHub profile at [soulaimane-edh](https://github.com/soulaimane-edh) to coordinate a private disclosure channel.

Include the affected workflow/node, version, impact, and safe reproduction steps, with secrets redacted. Do not test against a mailbox or infrastructure without authorization.

## Scope and support status

The workflow is a **prototype** and is not offered with an SLA, guaranteed remediation timelines or production security guarantees. All runtime and third-party integrations must be reviewed in your own environment. See [docs/SECURITY.md](docs/SECURITY.md).
